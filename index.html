How to read it

Value = (−1)sign × 1.mantissa × 2exponent − bias. The bias is 15, 127, 1023 or 16383 for 16, 32, 64 and 128 bits. When the stored exponent is all zeros the number is subnormal and the hidden bit is 0; when it is all ones the value is ±Infinity (mantissa all zeros) or NaN.

Inputs you can type: decimals (0.1, -2.5e-3), fractions (1/3), hex bit patterns (0x3FB999999999999A), binary patterns (0b0…), Inf, -Inf and NaN. You can also edit the sign, exponent or mantissa bits directly and press Enter. An exponent typed as +3 or -2 is read as the unbiased value.
